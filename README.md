# Social Media Post Generator

## Overview

This project is a Python application developed in Google Colab using the Google Gemini API.

The application generates ready-to-post social media captions based on:

- Topic
- Platform
- Tone

Supported platforms:

- LinkedIn
- Twitter/X
- Instagram
- Facebook

Each platform generates captions with different writing styles, lengths, and hashtags.

## Technologies Used

- Python
- Google Colab
- Google Gemini API
- Google Generative AI SDK

## Features

- Uses Gemini API
- Reads API key securely from Colab Secrets
- Supports four social media platforms
- Saves generated captions into text files
